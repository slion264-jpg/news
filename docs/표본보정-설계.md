# 표본 부족 보정 — 설계 문서

갈피의 단어 네트워크는 기사 232건 위에서 계산됩니다. 이 규모에서 파이(φ) 계수만으로
연결 여부를 정하면 우연한 겹침이 진짜 관계를 이깁니다. 이 문서는 문제를 수치로 확인하고,
바꾼 기준과 그 근거, 남은 한계를 적습니다.

측정일 기준 데이터: 2026-07-30 ~ 08-09, 기사 232건, 통제 어휘 119개, 분석어(df≥2) 108개.

---

## 1. 무엇이 문제였나

### 1.1 φ는 관계의 세기만 말하고 근거의 두께는 말하지 않는다

φ는 두 이진 변수의 피어슨 상관입니다. 값이 크다는 것은 "함께 나오는 경향이 강하다"는
뜻이지, "그렇게 판단할 만큼 많이 봤다"는 뜻이 아닙니다. 두 경우를 비교하면 분명해집니다.

| 상황 | n₁₁ | 각 단어 등장 | φ |
|---|---|---|---|
| 기사 2건짜리 단어 둘이 **우연히 한 번** 겹침 | 1 | 2, 2 | **0.496** |
| 30건씩 등장하며 **15건을 공유** | 15 | 30, 30 | **0.426** |

우연 1건이 진짜 관계를 이깁니다. 실제 데이터에서도 `공소기각 — 영장청구권`이 기사 1건으로
φ=0.402를 기록했습니다.

### 1.2 고정 임계값은 표본 크기를 모른다

기존 규칙은 두 겹이었습니다. `analyze()`가 φ > 0.02로 거른 뒤, 탐색기 슬라이더가 기본 0.20
이상만 그렸습니다. 두 값 모두 표본 크기와 무관한 상수입니다.

- φ = 0.02 는 N=232에서 χ² = 0.09, **p ≈ 0.76** — 무작위와 구분되지 않습니다.
  양의 상관 448쌍 중 437쌍이 통과해 사실상 거르는 역할을 하지 못했습니다.
- φ = 0.20 은 p ≈ 0.002로 낫지만, 위 표의 우연 1건(φ=0.50)을 걸러내지 못합니다.
  φ 크기로는 애초에 구분할 수 없는 종류의 문제이기 때문입니다.

### 1.3 실제로 화면에 무엇이 있었나

기본 설정(φ ≥ 0.20, 노드당 상위 6개)에서 표시되던 연결 **249개**의 근거를 세어 보면,

| 근거 기사 수 | 연결 수 | 비중 |
|---|---|---|
| 1건 | 16 | 6% |
| 2건 | 70 | 28% |
| 3건 | 44 | 18% |
| **3건 이하 합계** | **130** | **52%** |

절반이 넘습니다.

### 1.4 어휘 자체가 희소하다

분석어 108개의 문서빈도 중앙값은 5.5, **44%(48개)가 df ≤ 4**입니다. 희소어끼리의 쌍이
많을수록 1.1의 역전이 자주 일어납니다.

## 2. 바꾼 기준

φ 임계값 하나를 두 개의 관문으로 대체했습니다. 순서대로 적용합니다.

### 2.1 최소 공동등장 2건 (`MIN_CO = 2`)

기사 한 건에만 같이 나온 쌍은 후보에서 제외합니다. 1.1의 병리적 사례가 구조적으로
사라집니다. 표본이 커져도 유지할 값이라 상수로 둡니다.

### 2.2 피셔 정확검정 + FDR 보정 (`Q_FDR = 0.05`)

두 단어가 관측된 만큼 겹칠 확률을 근사 없이 계산합니다(초기하분포 우측 꼬리).

```
p = Σ(k=n₁₁ .. min(r₁,c₁))  C(r₁,k)·C(r₂,c₁−k) / C(N,c₁)
    r₁ = 단어 x 등장 기사 수,  c₁ = 단어 y 등장 기사 수,  N = 기간 내 기사 수
```

χ² 근사를 쓰지 않은 이유는 기대빈도가 5 미만인 칸이 흔하기 때문입니다. 이 조건에서
χ² 근사는 p값을 과소평가해 없는 관계를 만들어냅니다.

단어가 108개면 검정할 쌍이 5,778개입니다. 유의수준 0.05를 그대로 쓰면 우연히 유의해 보이는
쌍이 기댓값으로 289개 나옵니다. 벤저미니-호흐베르크 절차로 **거짓발견율(FDR)을 5% 이하**로
묶습니다. p값을 오름차순 정렬한 뒤 `p₍ᵢ₎ ≤ q·i/m`을 만족하는 가장 큰 i까지 채택합니다.

`m`은 **가능한 모든 쌍**(108×107/2)으로 잡습니다. 공동등장이 없는 쌍은 p=1이라 어차피
기각되지 않으므로 이 선택은 보수적일 뿐 결과를 왜곡하지 않습니다.

### 2.3 표본 크기에 따라 저절로 조정된다

이것이 고정 임계값 대비 핵심 이점입니다. 기간을 좁히면 통과하는 연결이 줄고, 데이터가
쌓이면 더 약한 관계까지 잡습니다.

| 구간 | 기사 N | 분석어 | 유의 연결 |
|---|---|---|---|
| 사흘 (08-07 ~ 08-09) | 38 | 26 | 15 |
| 하루 (08-04) | 45 | 65 | 23 |
| 전반 5일 | 102 | 76 | 74 |
| 후반 6일 | 130 | 74 | 103 |
| 이레 | 156 | 82 | 127 |
| **11일 전체** | **232** | **108** | **164** |

"유의 연결"은 통계 관문을 통과한 수이고, 화면에는 여기에 노드당 상위 6개 규칙이 한 번 더
걸립니다. 대개 같지만 이레 구간처럼 허브가 몰린 경우 1~2개가 더 빠집니다(127 → 126).

## 3. 바꾼 결과

| | 기존 (φ ≥ 0.20) | 신규 (n₁₁ ≥ 2 + FDR 0.05) |
|---|---|---|
| 표시 연결 | 249 | **164** |
| 연결된 단어 | 108 | 97 |
| 기사 1건 근거 | 16 | **0** |
| 기사 2건 근거 | 70 | 유의한 것만 잔존 |
| φ 최솟값 | 0.20 | 0.244 |

기존 249개 중 **162개가 새 기준을 통과**했고 87개가 탈락했습니다. 탈락한 87개 중 66개가
기사 1~2건 근거였습니다. 반대로 예전 φ ≥ 0.20 컷에는 걸렸으나 통계적으로는 유의한 연결
2개가 새로 들어와 합계 164개가 됩니다. 탈락 사례:

| φ | 근거 | 각 등장 | 쌍 |
|---|---|---|---|
| 0.46 | 2건 | 6, 3 | 소비자물가 — 한국은행 |
| 0.46 | 2건 | 6, 3 | 군기강 — 무인기 |
| 0.42 | 2건 | 11, 2 | 규제 — KT과징금 |
| 0.42 | 2건 | 11, 2 | 규제 — 개인정보 |

`소비자물가 — 한국은행`처럼 상식적으로 그럴듯한 쌍도 있습니다. 그러나 지금 데이터가
말할 수 있는 것은 "기사 2건에서 같이 나왔다"까지입니다. 그럴듯함은 근거가 아닙니다.
데이터가 쌓이면 이런 쌍은 저절로 돌아옵니다.

## 4. 구현

| 파일 | 내용 |
|---|---|
| `build.py` | `MIN_CO`, `Q_FDR`, `fisher_right()`, `analyze()` 내 BH 절차. 빌드 로그에 유의 연결 수 출력 |
| `explore.tpl.html` | 동일 로직의 JS 판. `lgamma()`(란초스 근사) → `lchoose()` → `fisherRight()` |
| `content.py` | 분석 방법 페이지 3장 가지치기 절, 7장 남은 과제 |

Python은 `math.comb`으로 정확한 유리수 연산을, JS는 로그 감마로 부동소수점 연산을 합니다.
계산 경로가 다르므로 **6개 구간에 대해 두 구현의 결과를 대조**해 유의 연결 집합이 완전히
일치함을 확인했습니다.

비용은 무시할 수준입니다. 피셔 검정은 공동등장 2건 이상인 후보(전체 기간 327쌍)에만 돌고,
합산 구간도 df 최댓값(59)에 묶입니다.

## 5. 남은 한계

### 5.1 통과한 연결도 흔들린다

기사를 복원추출로 다시 뽑아 분석하는 부트스트랩을 150회 돌렸습니다. 유의 연결 164개 중
**재현율 80% 이상은 60% 안팎**(난수씨앗을 바꿔 가며 98~102개), 재현율 중앙값은 0.86이었습니다.
통계 관문은 근거 없는 연결을 걷어낼 뿐, 없는 표본을 만들어 주지는 않습니다.

### 5.2 시간이 실질적 해법이다

φ의 유의성 임계는 √N에 반비례합니다. 하루 22건 기준으로,

| 경과 | 누적 N | p<0.05 임계 φ |
|---|---|---|
| 11일 (현재) | 232 | 0.129 |
| 45일 | 1,000 | 0.062 |
| 90일 | 2,000 | 0.044 |
| 180일 | 4,000 | 0.031 |
| 365일 | 8,000 | 0.022 |

데이터를 지우지 않고 누적하는 현재 정책이 이 지점에서 정확히 옳습니다.

### 5.3 더 빨리 줄이려면

- **일일 수집량 확대** — 완전한 날 기준 15~45건. 두 배로 늘리면 위 표의 기간이 절반이 됩니다.
  분야 편중(문화 8건 대 경제 60건)도 함께 완화됩니다.
- **분석 단위 세분화** — 태깅 단위를 기사에서 문단으로 내리면 N이 5~10배가 됩니다.
  "같은 문단에 나옴"은 "같은 기사에 나옴"보다 강한 관계 신호이기도 합니다.
  다만 태깅 파이프라인을 바꿔야 합니다.
- **희소 어휘 병합** — df ≤ 4인 48개를 상위 개념으로 묶으면 단어당 표본이 늘고
  검정할 쌍 수(m)가 줄어 이중으로 유리합니다.

### 5.4 다루지 않은 것

매체 편중은 이 작업의 범위 밖입니다. SBS 33건, 파이낸셜뉴스 31건이 상위인 현재 분포에서
특정 매체의 보도 습관이 단어 동시등장 구조에 영향을 줄 수 있으나, 이는 표본 크기가 아니라
표본 구성의 문제입니다.
